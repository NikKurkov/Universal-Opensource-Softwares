# Contributing to Universal Open Source Softwares

Thank you for helping grow this list! Contributions are welcome: new entries, description fixes, category suggestions and corrections.

## How to add a project

1. Make sure the project is **free and open source** and its repository is actively maintained.
2. Pick the category that fits best. If none fits, suggest a new category in your pull request.
3. Add one entry per line, in this exact format:

   ```
   - [Project Name](https://github.com/owner/repository) - A brief description of what the app does. (License: SPDX-ID)
   ```

4. Always link to the **original upstream repository**. Forks and personal mirrors will not be accepted.
5. Keep descriptions short, factual and professional. No marketing language, emoji or superlatives.
6. Keep entries alphabetically ordered within their category.

## Rules

- One pull request per project or one logical change.
- Include a short explanation of why the project belongs on this list.
- Check that the license listed matches the project's repository.
